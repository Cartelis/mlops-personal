# Saugumo skenavimas — 3 savaitė

Šioje darbo kopijoje skenai dar nesugeneruoti. Atlikite [praktikos seką](week3.md):
Trivy išsaugo tikrus CPU/ONNX JSON bei CPU SBOM į `docs/week3/`, o
`python3 scripts/week3.py scan-report --gate` sugeneruoja šią ataskaitą.

| Vaizdas | HIGH | CRITICAL |
|---|---:|---:|
| mlops-cpu:local | dar neskenuota | dar neskenuota |
| mlops-onnx:local | dar neskenuota | dar neskenuota |

CRITICAL vartas: dar nepatikrintas. Esant CRITICAL radinių publikavimas
sustabdomas. HIGH radinius peržiūrėkite ir pagrįskite sprendimą; fiktyvių
nulių nerašykite. GPU skeną atlikite atskirai pagal papildomas užduotis.
